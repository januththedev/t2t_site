What is T2T AI-X?

This is not an academic course or a generic prompting camp. It is a high-performance career acceleration cohort designed for the AI-assisted software engineering era.

Phase 1

4-Weeks Intensive AI-Native Acceleration

A high-density operational phase covering the mechanics of AI-assisted engineering:

  • Interactive live workshops & technical coaching
  • Hands-on AI-assisted SDLC workflows
  • Systems thinking & architecture engineering
  • Building structural AI-augmented systems
  • Personal capability tracking & portfolio creation
Phase 2

Guided Industry-Aligned Execution

Selected cohort members transition into practical execution spaces:

  • Collaboration on live sandbox projects
  • Exposure to realistic engineering backlogs
  • Code reviews and structural audit sessions

  • Advanced portfolio hardening for global readiness

Frequently Asked Questions

Everything you need to know about the AI-X acceleration structure.

Is this a beginner program?

No. T2T AI-X requires basic programming competency. You should understand syntax, logic loops, basic data structures, and database calls before applying.

Is this online or physical?

This is a hybrid accelerator. It includes virtual mentoring sessions, online backlog operations, and core physical workshop sessions at the TRACE premises in Colombo.

What is the weekly commitment?

Participants must commit at least 40 hours per week for code building, prompts creation, peer reviews, and mentorship standups. It is designed to mirror a full-time software engineering role.

Will this help me become industry ready?

Yes, AI-X is built to replace the standard academic-style project path with actual software backlog cycles. You will work with production-grade AI tools, architecture systems, and code review criteria.

Is this academic or practical?

Entirely practical. We skip textbook definitions to focus on real system execution, prompt pipeline design, software architecture structure, and collaborative repository operations.

Who should apply?

Final year IT/software engineering undergraduates, fresh graduates, junior developers, and self-taught coders who want to build global-ready operational engineering capacity fast.

Do I need prior AI experience?

No prior AI experience is required. We will teach you prompt engineering, copilot patterns, multi-agent frameworks, and database retrieval models from the ground up, assuming you have coding logic down.

What happens after the first 3 months?

Upon successfully completing the Phase 1 assessment gate, you will transition to Phase 2, where you will build advanced projects and collaborate on active sandboxes aligned with industry sponsors.
